Restaurar el codigo
-------------------
1. Descomprimir codigo.zip en una carpeta nueva.
2. Copiar config/backend__.env         -> backend/.env
          config/frontend__.env.local  -> frontend/.env.local
          config/frontend__.env.production -> frontend/.env.production
3. Backend:  cd backend
             python -m venv env
             env\Scripts\pip install -r requirements.txt
4. Frontend: cd frontend
             npm install


Restaurar los datos
-------------------
Con backend/.env apuntando a la base donde se quiere restaurar:

    cd backend
    env\Scripts\python manage.py migrate
    env\Scripts\python manage.py loaddata ruta\a\datos.json

loaddata escribe con los mismos id: reemplaza los registros que ya existan
con ese id y agrega los que falten. En una base vacia deja todo igual que en
el momento del backup.
